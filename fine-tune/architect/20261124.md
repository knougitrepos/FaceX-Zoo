# SurvFace 입력 변환의 소규모 개발 대조

2026-11-24 KST. 구현됨. 기존 2026-10-25의 FaceX-Zoo 학습·export 경계와 기존 캠페인 체크포인트 계약을 유지한다. 입력 변환의 영향은 별도의 10 epoch 파일럿에서 비교한다.

**결정.** Carbon의 s7e가 full-FR에서 10 epoch까지 전역 붕괴를 피했으나 같은 run의 FPIR 10% TPIR은 epoch 3보다 낮았다. 후속 실험은 독립 개발 인물에 고정한 단일 요인 대조로 구성한다. 기존 WD0 Parent의 hash와 native SurvFace 역할 CSV hash를 고정하고 허용된 FR 인물에서 학습, 등록 개발, threshold fit, 미등록 개발 집합을 분리한다. 저자가 사용한 Parent를 재현했다고 가정하지 않는다.

**실행 경로.** [파일럿 노트북](../notebooks/pilots/survface_input_control.ipynb) → modules/survface_input_pilot.py → 두 개의 256-class MagFace 학습 → 128개 인물 템플릿 → 미등록 fit에서 개별 threshold 고정 → 동일 등록·미등록 개발 자료에서 평가 → 외부 모델 루트의 facex/diagnostics/survface_input_pilot/RUN_ID. seed, 규모, 학습률, 10 epoch, 변환·증강의 적용 순서와 통과 규칙은 사전 고정한다. 원본 크기가 있는 training_set crop에서 두 변환을 시작한다. 데이터셋의 기존 112×112 처리본으로 종횡비를 추정하지 않는다.

**영향.** 00·03·04에서 새 파일럿을 안내한다. 01·02의 정식 실행 기본값은 False다. 02의 RUN_PARENT_BATCH_PROBE는 scripts/probe_parent_batch.py를 배치별 별도 프로세스로 실행해 8,631-class MobileFaceNet+ArcFace의 실제 정렬 이미지 처리량을 점검한다. 정식 Parent의 batch·optimizer 설정과 기존 선택 파일·inventory는 독립 관리한다. 적용 범위는 FaceX-Zoo이며 ronbun DB를 사용하지 않는다.

**검증 및 다음 결정.** 종횡비·padding, fit 동점, genuine 점수, Top-20 순위 조건을 시험한다. 파일럿 결과는 두 조건이 모두 완료되고 plan·summary hash가 일치할 때 읽는다. 기준을 통과해야 더 큰 개발 인물 대조를 검토한다. 24.80% 근접과 전체 모델 행렬 확장은 공식 gallery/시험 protocol, 고정된 후보, 반복 학습의 별도 검증이 필요하다. 탐색에 사용한 인물을 후속 최종 평가 표본으로 사용하지 않는다. 신규 Parent 실험에서는 동일 downstream·개발 protocol로 기존 Parent와 비교해야 한다. 현재 파일럿은 기존 WD0 Parent 하나만 허용한다.

**재실행과 한계.** 새 split·Parent·학습법을 시험할 때는 별도 실험 설정과 실행 ID가 필요하다. 단일 seed, 16장 이상 보유 인물의 작은 gallery, 미감사 VGGFace2 인물 중복은 추론 범위를 제한한다. 추출 가중치·임베딩 보존 및 결과 해석은 [파일럿 안내](../notebooks/pilots/HOW_TO_READ.md)를 따른다.
